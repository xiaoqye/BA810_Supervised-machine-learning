This project focuses on building and evaluating predictive models to assess credit default risk using the LendingClub dataset. Key steps include cleaning and preparing raw loan data, performing exploratory data analysis (EDA) to understand feature distributions and relationships, and applying feature preprocessing with scikit-learn Pipelines, including missing value imputation, scaling of numerical features, and one-hot encoding of categorical variables.

Multiple classification models, such as Logistic Regression, Support Vector Machine (SVM), Decision Tree, and Random Forest, were trained and compared. Model performance was evaluated using Accuracy, Precision, and F1-score, with special attention to class imbalance and the ability to identify risky loans. This helped compare the strengths and weaknesses of different models.
